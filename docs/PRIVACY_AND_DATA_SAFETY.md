# Privacy and Data Safety

This Build Week repository is a public demonstration package.

It intentionally excludes:

- production databases;
- real customer records;
- real balances;
- passwords;
- Android signing keys;
- keystore files;
- private configuration files;
- local AppData files;
- API keys or service credentials.

All screenshots use demo data only.

The core accounting logic remains deterministic and local-first. AI-assisted features are designed to be optional, read-only, and advisory.
